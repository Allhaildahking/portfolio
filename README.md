# ALLHAILDAHKING — Personal Portfolio

A personal website for **Destiny Growrich** (@allhaildahking), built around an X-inspired interface with its own identity and content.

## Pages

- **Home** — profile, timeline, notes, and recent project updates.
- **About** — background, interests, and how I approach building.
- **Projects** — a dedicated look at software projects and experiments.
- **Contact** — verified places to find me online.

Every page keeps the same dark interface, blue accents, profile identity, navigation, and familiar social-platform layout. The content changes by page, so it feels like a real website rather than one long page with anchor links.

## Preview

- Live site: https://allhaildahking.github.io/portfolio/
- Repository: https://github.com/Allhaildahking/portfolio

## Tech

- HTML5
- CSS3 (custom properties, Grid, Flexbox, responsive media queries)
- Vanilla JavaScript
- Google Fonts: Inter and DM Mono

No framework, package manager, or build step is required.

## Run locally

```bash
git clone https://github.com/Allhaildahking/portfolio.git
cd portfolio
python -m http.server 8000
```

Open http://localhost:8000.
